# Figure Descriptions

This file documents the purpose and visual features of the figures generated by `phyloseq_analysis.qmd`. It is aligned to the current `analysis_results/` outputs.

Reference tag used throughout: `[Wang et al. 2022]`

## Setup And Scope

### `setup/library_sizes.tiff`
Shows the sequencing library-size distribution across samples. The figure is used to judge whether the dataset has highly uneven sequencing depth and whether downstream rarefaction or depth-aware filtering is needed.

### `tables/meta_analysis_overview_table.csv`
Summarises the dataset structure across the full meta-analysis scope in table form. It gives the first-pass view of sample counts, study coverage, developmental-stage coverage, and the broad taxonomic breadth represented in the cleaned dataset.

### `figures/geographic_distribution_map.tiff`
Maps sample or study geography to show where the included material originates. This is a context figure rather than a statistical result: it helps the reader see whether the dataset is geographically concentrated or geographically broad.

### `tables/meta_analysis_scope_summary.csv`
Not a figure, but it underpins the overview panel by recording the scope counts used in the report.

## Taxonomic Composition

### `figures/top_phyla_composition.tiff`
Displays phylum-level composition as stacked abundance bars, organized by study and stratified by developmental stage. The plot emphasizes the dominant phyla, the study-to-study variation, and the relative contribution of each phylum across the seed and seedling subsets.

### `figures/phylum_composition_sankey_by_stage.tiff`
Shows the transition from developmental stage to phylum using an alluvial/Sankey layout. Band width reflects relative abundance and the plot highlights how the broad bacterial community is distributed between `Seeds` and `Seedlings`.

### `figures/class_composition_sankey_by_stage.tiff`
Displays developmental stage against bacterial class. It is a mid-level taxonomic summary intended to show whether the main community signal is carried by a small number of recurring classes or spread across many taxa.

### `figures/order_composition_sankey_by_stage.tiff`
Shows developmental-stage composition at order level. This figure gives finer resolution than class-level composition and is useful for seeing whether specific bacterial orders are enriched in seeds versus seedlings.

### `figures/family_composition_sankey_by_stage.tiff`
Shows stage-to-family composition. The family level is often the most interpretable compromise between broad phylum summaries and more sparse genus-level panels, so this figure is useful for reading dominant lineage shifts without overwhelming the reader.

### `figures/genus_composition_sankey_by_stage.tiff`
Shows the top 10 genera plus `Other` across developmental stage using a Sankey/alluvial layout. The figure is intentionally compact: it is meant to highlight the dominant genera, reduce label clutter, and show how those genera are distributed between seeds and seedlings.

## Alpha Diversity

### `figures/alpha_observed.tiff`
Shows observed ASV richness across the main comparison groups. This is a raw richness view and is used to identify whether one group tends to carry more observed features than another.

### `figures/alpha_shannon.tiff`
Shows Shannon diversity for the main dataset. This captures both richness and evenness, so it is the more balanced alpha-diversity view relative to observed richness alone.

### `figures/alpha_combined.tiff`
Combines the two principal alpha metrics into a single publication-style panel. The goal is to let the reader compare richness and evenness side by side without hunting through separate plots.

### `figures/alpha_richness_by_species.tiff`
Displays observed richness by host species, now faceted by developmental stage. This is the species-level alpha-diversity comparison and is useful for showing whether richness differences are driven by host identity, developmental stage, or both together.

### `figures/alpha_richness_by_cultivar.tiff`
Displays observed richness by cultivar, now faceted by developmental stage. This is the cultivar-level alpha-diversity comparison and is useful for showing whether richness differences are driven by cultivar identity, developmental stage, or both together.

### `figures/alpha_observed_by_developmental_stage.tiff`
Observed richness stratified by developmental stage. This is the direct stage comparison for richness and is one of the main figures for seed-versus-seedling contrast.

### `figures/alpha_shannon_by_developmental_stage.tiff`
Shannon diversity stratified by developmental stage. This is the stage comparison for diversity structure, showing whether one developmental stage has a more even or more complex community.

### `figures/alpha_observed_by_scientific_name.tiff`
Observed richness grouped by host scientific name. It is intended to show host-specific richness differences while keeping the broader stage stratification visible in the layout.

### `figures/alpha_shannon_by_scientific_name.tiff`
Shannon diversity grouped by host scientific name. This figure is useful when the goal is to compare host species while still preserving the developmental-stage context.

### `figures/alpha_observed_by_cultivar.tiff`
Observed richness grouped by cultivar. This figure is only informative where cultivar metadata is sufficiently populated; it is mainly useful for identifying cultivar-associated richness shifts.

### `figures/alpha_shannon_by_cultivar.tiff`
Shannon diversity grouped by cultivar. This is the cultivar counterpart to the richness plot and is intended to reveal whether cultivar aligns with changes in evenness.

### `figures/alpha_observed_by_author.tiff`
Observed richness grouped by author/study label. This acts as a study-batch view and helps show whether the apparent biological signal is confounded by publication or project identity.

### `figures/alpha_shannon_by_author.tiff`
Shannon diversity grouped by author/study label. This is the evenness analogue of the study-level richness plot and is useful for spotting study-specific shifts.

### `figures/alpha_observed_by_study_alias.tiff`
Observed richness grouped by study alias. This is a batch-effect diagnostic: it shows whether richness is separated by study rather than biology.

### `figures/alpha_shannon_by_study_alias.tiff`
Shannon diversity grouped by study alias. This is the same diagnostic for evenness-based diversity.

## Beta Diversity And Ordination

### `diversity/pcoa_bray.tiff`
The primary Bray-Curtis PCoA for the main cleaned dataset. This is the global ordination figure used to visualise community separation across the dominant metadata groups.

### `diversity/pcoa_jaccard.tiff`
The primary Jaccard PCoA for the main dataset. This focuses on presence/absence structure instead of abundance, so it highlights compositional turnover rather than abundance weighting.

### `diversity/pcoa_bray_genus.tiff`
Genus-level Bray-Curtis PCoA. This is a rank-reduced ordination designed to show community clustering at genus resolution instead of ASV resolution.

### `diversity/pcoa_jaccard_genus.tiff`
Genus-level Jaccard PCoA. This is the presence/absence counterpart to the genus Bray-Curtis ordination.

### `diversity/pcoa_bray_species.tiff`
Species-level Bray-Curtis PCoA. This version is useful when the user wants a more biologically interpretable ordination than ASV-level clustering.

### `diversity/pcoa_jaccard_species.tiff`
Species-level Jaccard PCoA. This displays binary species presence/absence clustering.

### `diversity/pcoa_bray_otuid.tiff`
OTUID-level Bray-Curtis PCoA. This is a rank-specific beta-diversity view used when the user wants the original OTU/ASV-like distance structure without aggregating to genus.

### `diversity/pcoa_jaccard_otuid.tiff`
OTUID-level Jaccard PCoA. This is the presence/absence counterpart to the OTUID Bray-Curtis ordination.

### `diversity/pcoa_bray_genus_by_developmental_stage.tiff`
Genus-level Bray-Curtis PCoA faceted by developmental stage. This is the key visual for showing community clustering separately within `Seeds` and `Seedlings`.

### `diversity/pcoa_bray_genus_by_scientific_name.tiff`
Genus-level Bray-Curtis PCoA grouped by host scientific name. It shows whether host identity drives visible separation in genus-level community structure.

### `diversity/pcoa_bray_genus_by_cultivar.tiff`
Genus-level Bray-Curtis PCoA grouped by cultivar. This is the cultivar-specific ordination panel and is only informative where cultivar metadata is substantial enough to interpret.

### `diversity/pcoa_bray_genus_by_author.tiff`
Genus-level Bray-Curtis PCoA grouped by author/study label. It is a study-batch diagnostic that reveals whether study identity is a major driver of ordination separation.

### `diversity/pcoa_bray_genus_by_study_alias.tiff`
Genus-level Bray-Curtis PCoA grouped by study alias. This is a more direct study-level batch view than the author grouping.

### `diversity/nmds_plot.tiff`
Non-metric multidimensional scaling plot built from the beta-distance matrix. This figure is used as a robustness check against the PCoA representation because NMDS is rank-based and often reveals the same structure from a different angle.

### `figures/umap.tiff`
UMAP embedding of the beta-distance structure. This is a nonlinear ordination used to inspect whether the sample clusters remain visible when the geometry is allowed to warp.

## Core Microbiome

### `figures/core_microbiome_abundance_occupancy.tiff`
Scatter plot of mean relative abundance versus occupancy/prevalence for core and flexible taxa. This shows the stability of taxa across samples and separates consistently shared taxa from occasional ones.

### `figures/core_microbiome_bar.tiff`
Bar summary of core versus flexible taxa contribution. This is a compact overview of how much of the community is made up of stable core taxa compared with the flexible fraction.

## Indicator And Differential Taxa

### `figures/indicator_species_plot.tiff`
Shows taxa selected by indicator-species analysis. This panel identifies features that are disproportionately associated with the target contrasts, especially developmental-stage separation.

## Correlation And Association

### `figures/top5_genus_stage_correlation_heatmap_by_plant_family.tiff`
Heatmap of the top 5 genera correlated with developmental stage, split by plant family. The tile color encodes Spearman rho and the annotation marks whether the BH-adjusted association is significant.

### `figures/top5_genus_stage_correlation_heatmap_by_cultivar.tiff`
Same correlation heatmap, but split by cultivar instead of family. It shows whether the developmental-stage association for dominant genera is conserved across cultivar backgrounds.

## Network And Multivariate Feature Discovery

### `figures/cooccurrence_network.tiff`
Co-occurrence network of taxa relationships. Nodes represent taxa, edges represent statistically supported associations, and the layout is used to show whether the community has a modular structure.

### `figures/volcano_deseq2.tiff`
Differential-abundance volcano plot showing effect size versus significance. This identifies taxa that are both strongly shifted and statistically supported in the contrast.

## Data-Quality And Workflow Diagnostics

### `figures/sequencing_depth_histogram.tiff`
Histogram of sequencing depth across samples. It is used to check whether coverage is well distributed or whether a subset of samples is under-sequenced.

### `setup/sample_statistics.csv`
Tabular companion to the setup figures. It records the basic sample counts and summary values used to interpret the first-stage QC panels.

## Notes

The smoke outputs in `analysis_results_smoke/` mirror the same figure set at reduced runtime settings. The figure descriptions above apply to both the smoke and full output trees.
